## Project

**Edgard in Kimeria** — a 2D arcade/platformer built with Godot 4.6, GL Compatibility renderer. Viewport: 640×360, pixel art aesthetic (Nearest texture filter). This is a port from a Flutter/Flame original at `../edgard_in_kimeria`.

## Running the project

Open in Godot 4.6 and press **F5**. No CLI build step — Godot manages compilation through the editor. The main scene is `scenes/game.tscn` (shows MainMenu → Start → loads forest1).

Export (when ready):
```
godot --export-release "<preset>" <output_path>
```

## Level setup (important — do once)

The two game levels must be generated by running the TMX import tool:

1. Open Godot editor
2. Open `scripts/tools/import_tmx.gd` in the Script Editor
3. Run it via **File → Run** (the play button in the Script Editor toolbar)
4. This creates `scenes/levels/forest1.tscn` and `scenes/levels/forest.tscn` from the Flutter `.tmx` files
5. After running, the tool can be deleted

The `TileSet` resource is at `assets/tilesets/forest.tres`. The tileset image is `assets/sprites/Tileset.png` (320×112, 16×16 tiles, 20 cols × 7 rows).

## Architecture

### Entry flow
`scenes/game.tscn` → `MainMenu` overlay → Start button → `GameManager.reset()` → `get_tree().change_scene_to_file(forest1.tscn)` → `level.gd._ready()` spawns all entities from `SpawnPoints` Marker2D nodes.

### Key scenes and scripts

| Scene | Script | Role |
|---|---|---|
| `scenes/game.tscn` | — | Entry point, holds MainMenu |
| `scenes/player.tscn` | `scripts/player.gd` | CharacterBody2D, all player logic |
| `scenes/levels/forest1.tscn` | `scripts/level.gd` | Level 1 (40×23 tiles) |
| `scenes/levels/forest.tscn` | `scripts/level.gd` | Level 2 (80×23 tiles) |
| `scenes/enemies/bat.tscn` | `scripts/enemies/bat.gd` | Flying enemy, Area2D, triggers bullet-time |
| `scenes/enemies/yellow_mob.tscn` | `scripts/enemies/yellow_mob.gd` | Ground enemy, chases player |
| `scenes/enemies/red_mob.tscn` | `scripts/enemies/red_mob.gd` | Ground enemy, melee attack |
| `scenes/objects/escalator.tscn` | `scripts/objects/escalator.gd` | AnimatableBody2D moving platform |
| `scenes/objects/falling_platform.tscn` | `scripts/objects/falling_platform.gd` | Falls 1s after player steps on it |
| `scenes/objects/collectable.tscn` | `scripts/objects/collectable.gd` | Coins and hearts |
| `scenes/objects/checkpoint.tscn` | `scripts/objects/checkpoint.gd` | Triggers level transition |
| `scenes/objects/bomb.tscn` | `scripts/objects/bomb.gd` | Hazard, triggers respawn |
| `scripts/game_manager.gd` | autoload | Coins, lives, level index, pause, sfx |

### Collision layers
| Layer | Value | Users |
|---|---|---|
| World (solid ground) | 1 | StaticBody2D floors/walls, AnimatableBody2D platforms |
| Player | 2 | Player CharacterBody2D |
| Attack hitbox | 4 | Player AttackHitbox Area2D |
| Enemies | 8 | Bat Area2D, YellowMob/RedMob CharacterBody2D |

- Player mask=1 (collides with world)
- Enemies mask=1 (collide with world), Bat detection zone mask=2
- Attack hitbox mask=8 (hits enemies)
- Collectables/checkpoints mask=2 (detect player)

### Spawning system
Levels have a `SpawnPoints` Node2D with `Marker2D` children. Each marker's name prefix (`PlayerSpawn_0`, `Bat_0`, etc.) determines which scene to instantiate. Properties are stored as node metadata (set by import tool, editable in Inspector → Metadata). `scripts/level.gd` spawns all entities in `_ready()`.

### Physics
- Gravity: 588 px/s² (set in Project Settings → Physics 2D and in player/enemy scripts as `9.8 × 60`)
- Player: `WALK_SPEED=100`, `JUMP_FORCE=-260`, `TERMINAL_VELOCITY=300`
- Bat bullet-time: `Engine.time_scale = 0.5` when player within 50px, reset on exit

## GDScript conventions

- Godot 4 GDScript: `@export`, `@onready`, typed variables
- Movement in `_physics_process(delta)` on `CharacterBody2D`; use `move_and_slide()`
- Signals: `checkpoint_reached`, `died`, `life_lost(n)` on Player; connect in `level.gd`
- Enemy defeat: call `enemy.get_hit()` from player attack or stomp
- `GameManager.play_sfx(path)` for fire-and-forget sounds
